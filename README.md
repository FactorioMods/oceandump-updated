# Ocean Dumping: Updated

Allows unwanted items to be dumped into Nauvis and Gleba water, Fulgora oil, or Aquilo ammonia oceans. Startup switches select which of these destinations allow dumping.

This continuation retains the original tile behavior and setting names while updating its declarations and ownership identity for Factorio 2.1.

Requires Factorio 2.1.24 or newer. Dumped items are discarded. The supplied destinations require Space Age; other planet liquids need matching support from their supplying mods.
